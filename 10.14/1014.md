# 10.14 安装 hadoop local 模式（解压 hadoop）

本次在集群 master 节点上操作：主机名 `master`，登录用户 `bigdata3`。软件统一放在 `~/software`（= `/home/bigdata3/software`），jdk 的安装包也在同一目录。

## 1.4 安装 hadoop local 模式

（课程文档里这一部分是 1.3）

hadoop 不用 apt 装，而是下载官方压缩包后解压使用：解压出来的目录就是后面要配的 `HADOOP_HOME`。

### 1.4.1 解压hadoop

（课程文档里这一节是 1.3.1）

压缩包 `hadoop-3.5.0.tar.gz` 已经放在 `~/software` 下。

**1) 进入软件目录，确认压缩包在**

```sh
cd ~/software
ls
```

此时应该能看到 `hadoop-3.5.0.tar.gz`。（如果 `ls` 里已经出现 `hadoop-3.5.0` 目录，说明之前已经解压过。）

**2) 解压**

```sh
tar -zxvf hadoop-3.5.0.tar.gz
```

参数含义：

- `-z`：按 gzip 处理（压缩包后缀是 `.gz`）
- `-x`：解压
- `-v`：显示解压过程
- `-f`：指定后面跟的文件名

解压默认就地展开到当前目录，不需要另外指定目标路径。

**3) 验证**

```sh
ls
```

解压后会多出一个 `hadoop-3.5.0` 目录，目录名就是压缩包去掉 `.tar.gz`：

```
hadoop-3.5.0  hadoop-3.5.0.tar.gz  jdk-17.0.12  jdk-17.0.12_linux-x64_bin.tar.gz
```

看到 `hadoop-3.5.0` 目录即为解压成功。该目录的绝对路径 `/home/bigdata3/software/hadoop-3.5.0` 就是下一步配置环境变量时 `HADOOP_HOME` 要填的值。
