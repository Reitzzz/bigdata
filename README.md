# bigdata

大数据课程（Hadoop）的实验记录仓库。每做完一次实验，按日期建一个目录，把当天的操作过程、命令和结果截图记在里面。

## 目录

- [9.30](9.30/930.md) — Hadoop local 模式环境准备：关闭 ufw 防火墙、安装 sshd、安装 JDK

## 实验环境

- 虚拟机：VMware 上的 Ubuntu 24.04，主机名 `reitzzz-VMware-Virtual-Platform`
- JDK：OpenJDK 17.0.20.1

## 笔记约定

- 一个日期一个目录（`9.30/` 对应 2026-09-30），笔记文件以日期命名（`930.md`），图片和笔记放在同一层目录。
- 笔记按「命令 → 实际输出 → 结果说明」组织：命令和能用文字表达的输出写成代码块，只有在必须看实际画面时才放截图，避免整篇都是图片。
- 图片使用有含义的文件名，如 `ufw-status-enabled.png`、`java-version.png`，不用 `image-1.png` 这类序号名。
